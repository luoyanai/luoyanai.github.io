Visual servoing with limited training images

To align a workpiece using a camera, a robot needs image features that stay attached to the part as it moves. We use foreground segmentation to extract those features when only a small training set is available.

Yan Luo, Gaoming Chen, Chao Liu, and Zhenhua Xiong

PaperVideo

Finding the workpiece

The detector locates the part in the camera image. A segmentation model then separates it from the background so that feature matching can focus on the part itself.

Using the image as feedback

We compare features in the current image with those in a reference view. Their displacement gives the visual servo controller an error signal for moving the workpiece toward the desired alignment.
